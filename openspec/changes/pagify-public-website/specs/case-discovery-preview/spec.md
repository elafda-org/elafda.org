## ADDED Requirements

### Requirement: Dedicated cases page
Case discovery SHALL be hosted on a dedicated `/cases` page linked from primary navigation on every public page and from the landing page's primary call to action. The page SHALL keep the early-preview framing near the representative records and SHALL carry its own document title.

#### Scenario: Visitor reaches case discovery
- **WHEN** a visitor activates the cases navigation link or the landing page's browse action
- **THEN** the cases page loads with the search, topic filters and representative case records

#### Scenario: Preview framing on the cases page
- **WHEN** the representative records are displayed on the cases page
- **THEN** nearby interface text identifies the early or preview state of the archive
